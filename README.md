# Portfolio Website (old)

This was my portfolio at [sameemul-haque.vercel.app](https://sameemul-haque.vercel.app). It has moved to **[sameem.dev](https://sameem.dev)**, and every page on the old site now redirects to its matching page there.

To see the old portfolio as it was, browse the code at the last commit before any redirects: [`e87a4fd`](https://github.com/sameemul-haque/portfolio-old/tree/e87a4fd163e711668e5a5c41ec8cb14dc7174389).

To run it locally:

```sh
git clone https://github.com/sameemul-haque/portfolio-old
cd portfolio-old
git checkout e87a4fd
npm install
npm run dev
```
